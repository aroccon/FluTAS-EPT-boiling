## GPU Porting of FluTAS-EPT-Boiling to GPU

-Base code: Lorenz version working on CPUs


## How to compile:
- compile_cpu.sh; compile on Leonardo in CPU mode using GCC - ✅
- compile_gpu.sh; compile on Leonardo in GPU mode using NvFortran (ex PGI) - 🚧
